# Fotos de los servicios

Coloca aquí una foto por servicio. En cuanto el archivo exista y se enlace en
`src/data.ts` (campo `image`), reemplaza automáticamente al placeholder.

## Nombres de archivo (uno por servicio)

| Servicio | Archivo |
| --- | --- |
| Canalización | `canalizacao.jpg` |
| Electricidad | `eletricidade.jpg` |
| Pintura | `pintura.jpg` |
| Tejados | `telhados.jpg` |
| Limpieza | `limpeza.jpg` |
| Montajes y reparos | `montagens.jpg` |
| Aire acondicionado | `ar-condicionado.jpg` |
| Paneles solares | `paineis-solares.jpg` |

## Dirección de arte (importante)

- **Con intención, no stock genérico.** Nada de "señor sonriendo con mono azul".
- Planos de **detalle**: una mano arreglando algo, una herramienta de calidad
  sobre una superficie limpia, el gesto del oficio.
- **Filtro cálido** y luz natural; tonos coherentes entre todas las fotos (la web
  ya añade un leve tinte cálido para unificarlas).
- Ideal: **fotos reales de vuestros propios trabajos** (lo más auténtico).

## Especificaciones

- Relación de aspecto **4:3**, mínimo **800×600 px** (recomendado 1200×900).
- Formato `.jpg` o `.webp`, optimizadas (< 250 KB cada una).
